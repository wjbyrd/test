My Faculty Mastery Quest

Open my-faculty-mastery-quest.html in a modern browser. The game HTML is self-contained; graph images are embedded and no question-assets folder is required. Keep the generated concept-reviews folder beside the HTML so the packaged review PDFs remain available.

To deploy, upload the complete package to GitHub Pages or another static host. Progress and game data stay in the learner's browser. The game does not collect email addresses or transmit gameplay data to a server.

Enabled modes: Standard Campaign, Timed Trial, Exam Drill, Quiz, Unlimited Practice, Legendary Mode, Score Attack, Trial by Graph, Fading Fortune, Risk & Reward

Checkpoint questions are assigned by their published difficulty. Optional checkpoint focus only narrows which eligible concepts supply a checkpoint; it never changes ordinary-question availability or question difficulty.
